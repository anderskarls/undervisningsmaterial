# Lektion 4: Källschema och jämförelse - fyra liv i imperiet

**Kurs:** Historia Nivå 1b | **Moment:** Antiken - framsteg för vem?

Andra varvet med källschemat - nu i Rom. Efteråt jämför ni Aten och Rom. Ha lektion 3-schemana till hands.

## Del 1: Källschema per station (9 min per station)

Samma schema som förra lektionen:

| Fråga | Ditt svar |
|-------|-----------|
| 1. Station och källa (bokstav) | |
| 2. Vem talar i källan? | |
| 3. I vilket syfte? Vilken tendens? | |
| 4. Vad säger källan om gruppens LEVNADSVILLKOR? Minst två konkreta saker. | |
| 5. Vems röst hörs INTE? | |
| 6. Citat eller referat - och vad gör det för användbarheten? | |

> **Tips vid station 2:** Claudias gravskrift beställdes av hennes make. Vad berömmer han henne för - och vad säger DET om idealet? Är idealet samma sak som verkligheten (jämför källa C)?

> **Tips vid station 3:** Läs lagtextens definition långsamt. Romersk rätt kallar slaveriet "i strid med naturen" - och reglerar det ändå i detalj. Vad avslöjar det?

**⭐ Fördjupning:** Reginas gravsten (station 4) - är hennes liv ett belägg FÖR eller MOT imperiet som framsteg? Kan det vara båda samtidigt? Anteckna - det här är rådslags-guld.

## Del 2: Jämförelsen Aten - Rom (par, efter rundan)

Välj TVÅ av de fyra grupperna och fyll i:

| | Samma sak i båda (kontinuitet) | Nytt eller annorlunda i Rom (förändring) | Blev det bättre, sämre eller bara annorlunda? |
|---|---|---|---|
| Grupp 1: ______ | | | |
| Grupp 2: ______ | | | |

**Krav:** använd orden *kontinuitet* och *förändring* i era formuleringar. "Rom var bättre" utan begrepp och belägg räknas inte.

> **Tips:** Konkret exempel slår allmänt tyckande. "Frigivna blev medborgare i Rom men inte i Aten" är ett belägg. "Slavar hade det bättre i Rom" är det inte - hade gruvslaven i Spanien det bättre än husslaven i Aten?

**⭐ Fördjupning:** Caracallas edikt 212 gav alla fria medborgarskap - och samtidigt uppstod skiljelinjen honestiores/humiliores. Blev riket mer jämlikt, eller bytte ojämlikheten bara språk? Motivera med belägg från stationerna.

**Spara allt.** Nästa lektion är rådslaget - era scheman från lektion 3 och 4 är era beläggkällor.
