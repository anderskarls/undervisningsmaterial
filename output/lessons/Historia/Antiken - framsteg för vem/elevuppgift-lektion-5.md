# Lektion 5: Eftervärldens rådslag

**Kurs:** Historia Nivå 1b | **Moment:** Antiken - framsteg för vem?

Ni är eftervärldens råd. Frågan på bordet: **Var antiken ett framsteg för människan?** Varje perspektiv ska höras innan rådet dömer. Historikerna är oense - nu är det er tur.

## Steg 1: Perspektivgruppen (ca 20 min)

Din grupp företräder ETT perspektiv: medborgaren, kvinnan, slaven eller provinsbon/metoiken. Bygg 3-4 **beläggkort** ur era källscheman från lektion 3-4 och klassmatrisen.

**Beläggkort (en per kort):**

| | |
|---|---|
| **Påstående** (vad hävdar ert perspektiv i framstegsfrågan?) | |
| **Belägg** (konkret fakta eller källa som stödjer det) | |
| **Källa** (vilken station/källa kommer belägget från?) | |

**Regler:** Ett kort utan källhänvisning är en åsikt, inte ett belägg. Ert perspektiv får peka åt BÅDA hållen - "framsteg i ett avseende, inte i ett annat" är ofta det ärligaste kortet.

> **Tips:** Kortet får läsas ordagrant i tvärgruppen - skriv så att det bär utan improvisation.

### Historikerkorten (tolkningsstöd)

**Ober-kortet:** Historikern Josiah Ober menar att det klassiska Grekland var ett historiskt undantag: befolkningen 25-dubblades, husen växte 350 %, vanliga löntagare tjänade 2,6-4,6 gånger existensminimum - välstånd som inte bara tillhörde kungar utan en bred medborgarmassa, tack vare rättvisa regler och demokrati.

**Finley/de Ste. Croix-kortet:** Historikern Moses Finley menade att antikens ekonomi var statisk och styrdes av status, inte utveckling. G.E.M. de Ste. Croix gick längre: välståndet skapades genom systematisk utsugning - slavarnas arbete betalade medborgarnas frihet.

**Fråga till er grupp:** Vilken historiker skulle ERT perspektiv ge rätt? Varför?

**⭐ Fördjupning:** Rådet dömer "antiken" - men epokbegreppet uppfanns i Europa 1 800 år senare. Hade ett persiskt eller kinesiskt råd känt igen frågan? Ta med tanken till tvärgruppen.

## Steg 2: Tvärgruppen - rådslaget (ca 26 min)

Ny grupp: fyra personer, ett perspektiv var. Följ rundorna EXAKT:

1. **Föredragning (2 min per person, ingen avbryter):** presentera ditt perspektivs beläggkort.
2. **Fri deliberation (8 min):** väg perspektiven mot varandra. Vad väger tyngst? Varför?
3. **Motargumentsrundan (obligatorisk):** var och en formulerar det starkaste argumentet MOT sin egen lutning. Startmening om det kärvar: *"Den som tycker tvärtom skulle säga att..."*
4. **Rådets dom:** skriv ett preliminärt gemensamt omdöme på omdömeskortet. Reservationer är tillåtna och ska antecknas med namn och skäl.

**Omdömeskort:**

| | |
|---|---|
| **Rådets preliminära dom** (1-3 meningar) | |
| **Det starkaste skälet FÖR domen** | |
| **Det starkaste skälet MOT domen** (från motargumentsrundan) | |
| **Reservationer** (namn + skäl) | |

> **Tips:** En dom med ett ärligt "MOT-skäl" är starkare än en enig dom utan. Domare som inte kan ange motargumentet har inte lyssnat klart.

**Allt skriftligt samlas in.** Beläggkorten och omdömeskorten är klassens gemensamma källbank när du skriver ditt EGET omdöme nästa lektion.
