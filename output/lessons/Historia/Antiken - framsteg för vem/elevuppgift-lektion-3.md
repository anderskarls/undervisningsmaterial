# Lektion 3: Källschema - fyra liv i polis-samhället

**Kurs:** Historia Nivå 1b | **Moment:** Antiken - framsteg för vem?

Ni roterar mellan fyra stationer (10 min per station). Vid varje station: läs källan i källhäftet och fyll i ett källschema nedan. Ni arbetar i par men skriver var sitt schema.

**Kom ihåg från förra lektionen:** en källa har alltid en avsändare med ett syfte (tendens) - och den täcker aldrig alla (representativitet).

## Källschema (ett per station - fyra kopior i häftet)

| Fråga | Ditt svar |
|-------|-----------|
| 1. Station och källa (bokstav) | |
| 2. Vem talar i källan? (person, roll, grupp) | |
| 3. I vilket syfte? Vilken tendens kan det ge? | |
| 4. Vad säger källan om gruppens LEVNADSVILLKOR? Minst två konkreta saker. | |
| 5. Vems röst hörs INTE i källan? | |
| 6. Citat eller referat? Vad gör det för hur du kan använda den? | |

> **Tips vid fråga 2:** "Vem talar" är inte alltid den källan handlar om. I källa B talar Perikles OM kvinnorna - talar någon kvinna?

> **Tips vid fråga 4:** Levnadsvillkor = vardagens ramar: arbete, ägande, makt över sitt liv, trygghet, familj.

**⭐ Fördjupning (valfri, efter varje station):** Vad kan den här källan INTE belägga om gruppens villkor - och vilken sorts källa skulle behövas för att fylla luckan?

## Efter rundan: klassmatrisen

Vi samlar allas fynd i en gemensam matris på tavlan. Var beredd att bidra med:
- Ett konkret levnadsvillkor för "din" sista grupp
- Ett svar på: vems röst saknades vid din sista station?

**Viktigt:** Idag tar vi INTE ställning i momentfrågan. Idag inventerar vi. Positionerna kommer i rådslaget (lektion 5) - då är dessa scheman ert råmaterial. Spara dem.
