# Forskningsöversikt — Pedagogiska presentationer

## Bakgrund

Jag ville ta reda på vad forskningen säger om hur man utformar presentationer som maximerar elevernas lärande. Rapporten bygger på 26 källor — framför allt meta-analyser och systematiska översikter från 2020–2025, med Richard Mayers multimedialärande och John Swellers kognitiva belastningsteori som grund.

Fullständig rapport med alla 26 källor: [[Forskningsrapport — Pedagogiska presentationer (fullständig)]]

## De viktigaste principerna

### Mayers principer (validerade i 1 189 studier, 78 177 deltagare)

| Princip | Vad den innebär | Effektstorlek (d) |
|---------|----------------|-------------------|
| Temporal kontiguitet | Visa ord och bild samtidigt, inte sekventiellt | 1,22 |
| Spatial kontiguitet | Placera text intill relevant bild | 1,10 |
| Modalitet | Använd tal + bild istället för text + bild | 1,02 |
| Redundans | Visa inte samma text som du läser upp | 0,86 |
| Koherens | Ta bort irrelevant material | 0,86 |
| Signalering | Markera viktigt med färg, pilar, fetstil | 0,46 |

### Assertion-evidence-metoden

Byt ämnesrubriker mot påståendesatser. Istället för "Orsaker till första världskriget" → "Allianssystemet förvandlade en regional konflikt till ett världskrig", med en kartbild som visuellt stöd. Ger +17 procentenheter bättre förståelse och 10x färre missförstånd.

### Aktiva inslag

- **Pausprocedurer**: Tre 2–3 min pauser per 50-minuterslektion. 83,6% rapporterar förbättrad återkallelse.
- **Retrieval practice**: Fråge-slides var 10:e minut som kräver återkallelse utan anteckningar.
- **Think-pair-share**: Tänk–diskutera i par–dela med klassen. Var 15:e minut.
- Aktiva inslag höjer prestationen 0,27–0,50 SD — särskilt för lågpresterande elever (0,43 SD).

### Tre övergripande mönster

1. **Kanalseparation** — text på slides konkurrerar med lärarens röst om samma kognitiva resurs. Använd bilder + tal istället.
2. **Subtraktion > addition** — de starkaste principerna handlar om att *ta bort* (irrelevanta bilder, redundant text, dekorationer).
3. **Presentationen är en lärandemiljö, inte ett dokument** — hur slides integreras med aktiviteter är viktigare än slide-designen i sig.

## Koppling till E/C/A-differentiering

Aktiva pauser fungerar som differentieringsverktyg: E-elever får stödstruktur genom pardiskussion och återkallning, medan A-elever kan utmanas med mer komplexa frågor under samma pauser.

## Checklista

| Princip | Fråga |
|---------|-------|
| Modalitet | Stödjer slides med bilder (inte text) det jag säger muntligt? |
| Redundans | Läser jag INTE upp texten på slides ordagrant? |
| Koherens | Har jag tagit bort ALLA bilder som inte direkt stödjer lärandemålet? |
| Kontiguitet | Är text placerad direkt intill relevant bild? |
| Signalering | Använder jag färg/pilar/fetstil för att markera det viktigaste? |
| Assertion-evidence | Har varje slide en påståendesats istället för en ämnesrubrik? |
| Segmentering | Har jag lagt in aktiva pauser var 10–15 minut? |
| Retrieval practice | Finns det frågeslides som kräver återkallelse? |
| Väntetid | Planerar jag 3–5 sekunders väntetid efter varje fråga? |
| Narrativ | Bidrar varje slide till en progressiv berättelse? |
